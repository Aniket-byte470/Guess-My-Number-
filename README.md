# 🎯 Guess-My-Number

An interactive number guessing game built with HTML, CSS, and JavaScript.  
Try to guess the secret number between 1 and 20! The game provides feedback on your guesses and keeps track of your score and high score.

## 🕹️ How to Play

- Click on the "Check!" button to submit your guess.  
- The game will tell you if your guess is too high, too low, or correct.  
- You start with a score of 20. Each incorrect guess decreases your score by 1.  
- If you guess correctly, your current score is compared to your high score.  
- Click "Again!" to reset the game and play again.

## 🚀 Features

- Random number generation between 1 and 20.  
- Real-time feedback on guesses.  
- Score tracking and high score comparison.  
- Responsive and user-friendly interface.

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript
